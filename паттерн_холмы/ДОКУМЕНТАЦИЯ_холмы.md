# Паттерн «холмы» (seigaiha / акварельная чешуя): как решали и к чему пришли
Дата: 2026-10-09. Плитка бесшовная, 2175×2175 px (150 dpi), 14,5″. 2175 = 8700/4 и 4350/2, поэтому ложится на холсты Printify без подгонки.
Образец: готовый рулон дизайнера (тёмные полосы-сетка, под ними светлые линии, акварельная заливка сине-бирюзовая). Из образца берём ТОЛЬКО геометрию дуг (примерно) и общую манеру, пикселей рисунка не копируем.

## 1. Финал (что оставили)
Плитка v10: холмики рисует и расставляет КОД (Gemini для финала не нужен). Ровная заливка #567783, тёмная полоса толстая, неровная, у каждого холмика своя толщина.
Команды (нужны python3, numpy, pillow, scipy, scikit-image; спрайты считаются ~5 мин, сборка ~1 мин, долгие команды запускать в фоне):
```
python -I рисую_холмы.py --arcs дуги_51.json --out спрайты --n 24 --width 1268 --bandw 120
python -I сборка_сетка.py --elems спрайты --rowfrac 0.28 --dropmin 600 --halfw 80 --halfl 150 --ramp 90 --flat 567783 --out плитка.png
```
Результат: плитка.png (+ _2x2.jpg превью и _стык_центр.jpg кроп 1400×1400 вокруг стыка в полном размере для проверки).
Выдача пользователю: плитка 1×1 / 2×2 / 3×3 / 2×4 в JPG q92, 150 dpi, архивом (файлы >8000 px через SendUserFile картинкой не отправляются, только в zip; лимит 30 МиБ).
Если нужна текстура: `--tex текстура.jpg --texmean 567783` (текстура из Gemini, раскладывается зеркально, у каждого холмика свой кусок) или `--flat 567783 --grain 3.5` (ровная с мелким зерном). Пользователю текстура Gemini показалась «грязноватой», выбрана ровная заливка.

## 2. Как устроен рисунок (понять один раз, дальше всё из этого)
Это не «камушки», налезающие друг на друга, а СЕТКА: тёмные полосы одной ширины образуют непрерывные волнистые линии, в узлах они сливаются. Светлые линии (белая и бледно-мятная, 1–3 штуки) идут только вдоль ВЕРХНЕГО (внутреннего) края полосы. Нижнего контура у холмика нет. Ряды стоят в шахматке, нижний ряд закрывает юбку верхнего, видна только дуга и часть заливки.

## 3. Хронология: что пробовали, что не сработало, как решили
1. Gemini рисует листы отдельных холмиков (3×3 на белом), код режет и расставляет по тору. Проблемы: под холмиками просвечивал фон (юбка короткая); разброс форм у Gemini либо нулевой (все одинаковые), либо слишком большой (потерян единый стиль, а «один стиль у всех» и есть суть паттерна); заливка грязная (потёки, кляксы).
2. Снял формы дуг с образца: тёмные дуги слиплись в сетку, поэтому режутся СВЕТЛЫЕ линии под дугами (они отдельные, по одной на холмик). Скелет линии, кубический полином, отбор плавных горбов (51 из 55). Скрипт `снять_дуги.py`.
3. Из дуг сделал силуэты-направляющие для Gemini (серая линия + светло-серая область, холмик полностью: дуга продолжена вниз по обоим бокам до общего основания, оба конца на одной горизонтали, юбка 1,5 ширины). Gemini держал форму, но заливка опять была не та, а главное: стало видно, что рисунок это «сетка» (см. п.2), и метод листов был оставлен (скрипт направляющих не сохранён: рисовалась PIL-ом серая линия и светло-серая область по дуге).
4. Перешли на процедурные спрайты (`рисую_холмы.py`). Итерации по замечаниям пользователя (каждая была отдельной версией):
 - острые верхушки и выемки по центру холмика -> верх строго ВЫПУКЛЫЙ (выпуклая оболочка контура) и скруглён;
 - торчащие вниз концы полос («хвосты») и острые углы -> полоса идёт только по верху и пологой части плеч (ограничение по крутизне), дальше сужается в клин и уходит ПОД соседа, чтобы конец вливался в его дугу (как узлы сетки на образце);
 - прямые углы там, где сосед накрывал только центр полосы -> клин начинается там, где накрыты центр И оба края полосы;
 - холмики вдвое шире -> `--width 1268`, 3 в ряду;
 - перекрытие слишком сильное, видны одни верхушки -> реже ряды (`--rowfrac 0.28`);
 - выбиваются из ритма «маленькие» -> это пологие дуги (подъём меньше ~600 px): отбор `--dropmin 600` (15 из 24 спрайтов) и центровка по вершине, а не по ширине, чтобы вершины лежали на ровной шахматке;
 - текстура Gemini «грязновата» -> ровная заливка;
 - «тёмные линии толще в 2 раза, разной толщины, неровные, натуральные» -> `--bandw 120`, у каждого холмика своя толщина (0,8–1,25), толщина гуляет вдоль линии (±22%), внешний и внутренний край идут каждый со своей лёгкой волной; светлые линии ведутся по внутреннему краю и повторяют его неровность.
5. Пользователь выбрал v10.

## 4. Технические приёмы (общие для будущих паттернов)
- Тор: всё, что уходит за правый край, возвращается слева (девять сдвигов или `x % W`). Шов получается по построению.
- Вертикаль при перекрывающихся рядах: красим ТРИ копии плитки подряд по y (верх, середина, низ), берём среднюю. Иначе «нижний закрывает верхний» по кругу даёт шов.
- Шов проверять на КАЖДОЙ границе повтора: перепад на стыке сравнивать с перепадом внутри (скрипт печатает) и смотреть крест из четырёх копий в полном размере (кроп вокруг стыка). 2×2 в уменьшенном превью шов не показывает.
- Полоса обрезается клином по карте «владельца пикселя» (кто сверху): индекс ближайшей точки кривой по пикселю (`nmap`), точка накрытия соседом `covered_full`, затем клин за `--ramp` индексов.
- Контроль дыр: непокрытая холмиками площадь должна быть 0.0000% (`сборка_холмов.py` сам удлиняет юбку, `сборка_сетка.py` печатает долю пикселей цвета фона).
- Спрайты хранятся слоями (заливка отдельно, полосы отдельно) в `.npz`: можно подменить заливку (текстура/ровная/зерно), не пересчитывая формы.
- Дуги в `дуги_51.json`: ширина `w` и 4 коэффициента кубики `p` на дугу (порядок важен, на него завязан цикл спрайтов). Сырые точки получаются из образца `снять_дуги.py` (нужна картинка образца и рамка полотна `box=(125,0,1080,880)` для этого образца).

## 5. Инструменты и методы (кроме финального)
- `сборка_холмов.py` + `вырезка_холмов.py`: метод «элементы из листов Gemini на белом/прозрачном фоне -> расстановка рядами по тору с перекрытием, три копии по y». Годится для любых перекрывающихся рядов (чешуя, черепица, листья), если элементы нарисованы с длинной юбкой. Параметры: `--cols`, `--overlap`, `--rowfrac`, `--jx --jy`, `--scale --rot --tone` (для «чисто» ставим 0), `--wash --grain`.
- `редактор_паттерна.html`: редактор в браузере (тор слева, сетка справа, Ctrl+колесо плавный зум, элементы мышью, выгрузка плитки заданного размера, сохранение проекта). Открывается двойным кликом.
- `холсты_ситец.py`: плитку 2175 кладёт на холсты Printify 4350×2700 / 8700×5400 / 8700×16200 / 8700×27000 пиксель в пиксель с проверкой каждой границы повтора. Для холмов холсты НЕ собраны (не просили).

## 6. Что просит пользователь (правила работы, соблюдать)
- Промпты для Gemini ВСЕГДА полные, готовые к вставке, без слотов; в конце сказать, что прикладывать. Если просят «просто дай тексты промптов» — дать только тексты.
- «Возьми то, что я скинул, и сделай 2×2» / «наложи эту схему» = буквально, без перерисовки и «улучшений».
- Шов проверять на каждой границе повтора, 2×2 смотреть в полном размере.
- Не делать ничего, пока сказано «обсуждаем / не делай / брейншторм». Отвечать на заданный вопрос, а не на соседний. («Я тебя что спросил?»)
- Не переделывать то, что пользователь назвал хорошим; менять только названное. Называть изменения честно: «дорисовал линии», а не «переделал» (был случай, когда пользователь ругал за «переделал», хотя форма была та же).
- Если пользователь рисует на скриншоте, обводка может быть сделана на 2×2 (не на плитке): сначала уточнить по контексту, куда относится.
- Присылая картинку на проверку, отправлять файлом для скачивания; если пользователь просит скачать, то отправлять именно файлы, а не пересказ.
- Образец дизайнера не копировать пикселями и не вырезать из него готовые мотивы для продажи: брать геометрию и манеру.
- Всё нужное на Google Drive (картинки тоже, такого запрета нет; но через коннектор картинка = base64, большие файлы дорого и рискованно, крупные отдавать архивом в чат). Старые версии файлов на Drive сразу в корзину, не копить хлам.
- Грубый юмор пользователя не обыгрывать, отвечать по делу.
