# Паттерн 2 — «ситец / grandmillennial chintz»: полная документация процесса

Дата записи: 2026-10-09. Ветка: `claude/vibrant-wright-mh2fe7`, папка `паттерн_ситец/`.
Контекст: Etsy + Printify «Fabric by Yard, Cotton Twill», MWW On Demand, 150 dpi, холсты 4350×2700 / 8700×5400 / 8700×16200 / 8700×27000 (9×9 исключён). Паттерн 1 (зайцы) закончен, см. `паттерн_зайцы/`.

## 1. Цель
Бесшовный «тканый» паттерн в стиле ситца: лозы проходят сквозь плитку и замыкаются на краях; без мелкого конфетти; пересечения лоз «над/под» как в ткани. Элементы рисует Gemini, собирает и проверяет код.

## 2. Ключевые идеи (как это работает)
1. **Тор.** Плитка = поверхность, где правый край склеен с левым, верхний с нижним. Всё, что уходит за правый край, возвращается слева. Бесшовность получается по построению.
2. **Замкнутые лозы.** Линия на торе замыкается только при рациональном наклоне (p,q) (p сторон плитки по x и q по y за петлю). Длина петли = R·√(p²+q²). Допустимые углы: 45°, 26.6° (2:1), 63.4° (1:2), вертикаль, горизонталь. Произвольный угол не замкнётся.
3. **Лента (border repeat).** Gemini рисует горизонтальную ленту, у которой левый и правый край совпадают (стебель на той же высоте, толщине, наклоне). Код кладёт ленту вдоль лозы. Если лента — целая петля (n=1), на лозе нет повторов, украшения стоят там, где нужно.
4. **Склейка без светлого шва.** Края ленты полупрозрачны; чтобы стыки не светились, период берётся из утроенной ленты и вырезается с запасом ±36 px (`piece()` в `сборка_геометрия.py`).
5. **Над/под в узлах.** Маска «только стебель» (связная область цвета стебля от левого края ленты, +3 px) → в узлах две лозы по очереди поднимаются поверх (мягкий круг r≈46, feather 12). Цвет по композиту не угадывать — были рваные артефакты.
6. **Схема доминант (идея пользователя).** Каждая лоза — свой тип украшений, украшения только в отмеченных кругах; пересечения вне кругов — голые стебли, узлы разгружены. Круги далеко друг от друга.
7. **Направляющая ленты.** Для Gemini рисуется изображение: цветная кривая = изгиб этой лозы в ленте, чёрные круги = места украшений. Gemini рисует лозу по кривой, украшения в кругах. Сами линии/круги рисовать запрещено.

## 3. Технологические ловушки (что уже ломалось)
- Gemini копирует композицию приложенного референса → прикладывать только лист образцов + направляющую, не готовые ленты.
- Gemini крупнит украшения за пределы кругов → в промпте задавать размер через диаметр круга (≈30% высоты картинки) и «целиком внутри», запрет выходить. Если не помогает: рефы с закрашенными светло-серыми кругами.
- Виноград: Gemini рисует гроздь вниз от лозы, лист в круге, а гроздь ниже круга; нижние ягоды «размываются» в полупрозрачность (в лентах C v3). Решение: центр грозди = центр круга, «ягоды чёткие, без размытия», перегенерировать.
- Цвет направляющей: зелёная кривая похожа на стебель → если Gemini рисует её, перекрасить в серый.
- Над/под: на лентах схемы v3 стебли тонкие (≈14 px), `сборка_геометрия.py` находит всего 3–10 пересечений вместо возможных 13–18 (порог `mk.sum()<30`, маска стебля обрезается, или наклонные пересечения мелкие). Не починено.
- Ограничения SendUserFile: изображения >8000 px и файлы >30 МиБ не отправляются.
- Не заливать картинки на Drive через коннектор — только текст и скрипты.
- Стоп-хук требует коммит/пуш: `git add -A . && git commit && git push -u origin claude/vibrant-wright-mh2fe7`.
- Объяснения пользователю: без «хитрости». Если просит «наложи эту картинку» — накладывать ИМЕННО её (multiply), а не перерисовывать.

## 7. Решение пользователя на сегодня (конец сессии) и план на завтра
Пользователь: «Оставить только 2 линии, а остальное другим паттерном делать, но это завтра». Идея: из схемы v3 оставить 2 лозы (вероятно A и B или те, что дали лучшие ленты), остальной «наполнитель» делается другим паттерном/слоем. Уточнить завтра, какие 2 линии и как комбинировать (фоновый второй паттерн под лозами?).
Остальные хвосты:
1. Починить над/под (`сборка_геометрия.py`/`сборка_по_узлам.py`), найти все пересечения.
2. Перегенерировать ленту C (виноград): центр грозди = центр круга, ягоды чёткие, внутри круга.
3. Выбрать плотность (оставить, добавить круги или слой).
4. Холсты Printify из плитки ситца: ширина плитки должна делить 8700 нацело; разрез раппорта искать как в `паттерн_зайцы/холсты_printify.py`.
5. Обновить на Drive старые копии файлов зайцев (ПРОМПТЫ_элементы.md и др.) — новое создавать, старое в корзину только с разрешения.

## 8. Команды (воспроизведение)
```bash
cd /home/user/1/паттерн_ситец
python -I узлы/схема_подбор_v3.py --iters 20000 --out узлы/схема_v3      # схема из 4 лоз (~8 мин)
python -I узлы/направляющие_v3.py                                         # 4 направляющих + схема_v3_ленты.json
# → сгенерировать 4 ленты в Gemini (промпты в ПРОМПТЫ_ситец.md), положить как лента/схема3_A..D.png

python -I узлы/наложение_схемы.py --tile плитка_схема_v3_a.png            # сравнить план и результат
```

## 10. Дополнение (после основной записи): идея «два слоя» и пример
- Идея пользователя на завтра: оставить 2 лозы схемы v3, остальное закрыть другим паттерном (фон). Слои с разным шагом повтора допустимы, если шаг кратен плитке (фон R/n, n целое; лозы — целая петля). Это «полиритм» в текстиле (ditsy-фон под крупными мотивами).
- Пример: `фон/фон_и_лозы.py` (фон из бледных вырезок цветов и листьев, шаг R/4, + лозы A и B из `сборка_по_узлам.py --params узлы/параметры_v3_AB.json --prefix схема3_ --out фон/перед_AB.png`). Результат `фон/пример_2_слоя.png` и `_2x2.jpg`.
- ОШИБКА, найденная пользователем: первая версия фона обрезала вырезки по краям под-плитки (в PIL `alpha_composite` пропускал копии с отрицательным смещением), листья были срезаны вертикальной линией каждые 512 px. Я проверял шов только по внешним краям плитки 2048 и смотрел 2×2 в маленьком превью. Исправлено: `tile.paste(m, pos, m)` со всеми 9 смещениями (обёртка по тору) + проверка швов на границах под-плиток (`ФОН отдельно: на границах … внутри …`). Урок: всегда проверять каждую границу повтора, и смотреть 2×2 в полном размере, а не в превью.
- Фон в примере грубый (жёсткая сетка из колонок, вырезки из лент). Для настоящего варианта: сгенерировать в Gemini маленькую ditsy-плитку (травка, крошечные цветы) и повторить с шагом R/4.
- Пользователь просит показывать буквально то, что он просит: «возьми то, что я скинул, и сделай 2×2» = склеить 4 копии его картинки без перерисовки.
